# BIBO STOR — إعداد Supabase

## 1) إنشاء المشروع
1. أنشئ مشروعاً جديداً في Supabase باسم `bibo-stor`.
2. اختر كلمة مرور قوية لقاعدة البيانات واحتفظ بها في مدير كلمات المرور.
3. بعد اكتمال إنشاء المشروع، افتح **SQL Editor**.

## 2) إنشاء الجداول والصلاحيات
1. افتح الملف `schema.sql` من هذا المجلد.
2. انسخ محتواه كاملاً إلى SQL Editor.
3. شغّل الاستعلام وتأكد من ظهور رسالة نجاح.
4. لا تضع أي مفتاح سري داخل ملفات GitHub Pages.

## 3) حساب المدير
1. فعّل تسجيل الدخول بالبريد وكلمة المرور من **Authentication**.
2. أنشئ حساب المالك من صفحة التسجيل بعد ربط الواجهة لاحقاً.
3. من SQL Editor، نفّذ استعلام ترقية الحساب بعد استبدال البريد:
   ```sql
   update public.profiles
   set role = 'admin'
   where id = (
     select id from auth.users
     where email = 'YOUR_OWNER_EMAIL'
   );
   ```
4. لا تمنح دور admin من بيانات المستخدم القابلة للتعديل في المتصفح.

## 4) الصور والطلبات
- أنشئ Storage bucket باسم `product-images` بعد تحديد سياسة الوصول.
- اترك رفع الصور وتعديل المنتجات للمدير فقط.
- لا تسمح للمتصفح بإنشاء طلبات مباشرة. يلزم إنشاء Edge Function تتحقق من الأسعار والمخزون وتحسب المجموع على الخادم قبل حفظ الطلب.
- لا تفعّل الدفع الإلكتروني حتى يتم اختيار مزود مناسب والحصول على حساب تاجر ومفاتيح API رسمية.

## تنبيه
هذا الإعداد يجهز مخطط قاعدة البيانات فقط. لا ينشئ مشروع Supabase ولا يربط الموقع تلقائياً، ولا يفعّل تسجيل الدخول أو لوحة الإدارة أو الدفع أو الشحن بمفرده.
